# Critique Field Manual

A shared language for critique and a shared sense of tempo.

## Overview

This web page provides a framework for studio critique that focuses on witnessing what work is actually doing, rather than imposing external judgment or taste.

## The 4-Card Critique Deck

1. **Witness** — What is actually happening on screen? What do you observe, not assume?
2. **Name the System** — What rules/logic does the work appear to be following?
3. **Assumption Check** — What does the work assume about the viewer, context, or meaning?
4. **Next Experiment** — What single change should be tested next (today)?

## Studio Rhythm: Fast → Slow

- **Fast** = Generate a playable fragment quickly (ship early)
- **Slow** = Refine clarity, interaction, and intent (make it legible)

## Hidden Features

- **Easter Eggs**: Three mantras hidden throughout the page
- **Keyboard Shortcuts**: Press `w`, `s`, `a`, `e` to navigate to each card
- **Interactive Phases**: Click on Fast/Slow phases to adjust rhythm speed
- **Scroll Effect**: Scroll to reveal hidden messages
